# CommsAlign

## Platform

Web. The class demonstration comes first. The same workflows should also make sense to managers using the tools in practice.

## Stack

The user delegated the stack choice. Use Flask, server-rendered HTML, CSS, and small amounts of JavaScript, reusing the Python domain modules. Replace Streamlit as the app runtime.

## Users and jobs

- Class evaluators need to understand and try both tools in a short demo.
- A manager writing a task instruction or feedback needs to review a draft against a rubric before sharing it.
- A manager reviewing aggregated team survey results needs to identify signals, check the evidence limits, and prepare a discussion.

## Product commitments

- Keep the CommsAlign name and selected navy and teal CA monogram.
- Keep Message Coach first and Team Diagnostic second in navigation.
- Keep explicit consent before sending a draft to GW Azure. Review scores are provisional model judgments.
- Use synthetic team survey data for the demo. Preserve minimum-response suppression and withhold scores, prompts, and downloads for suppressed groups.
- Preserve discussion notes and exports with their session-only and non-identifying scope.
- Use keyboard-accessible navigation and forms, readable contrast, and layouts that work on desktop and mobile.
